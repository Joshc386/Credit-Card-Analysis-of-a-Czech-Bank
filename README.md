# Project Aims
The aim of this is to investigate whether there are characteristics that define whether an individual is likely to pay their loan back or default. This will be split up into several pieces of analysis and be looked at through several lenses.

## Date
The original data comes from The Berka Dataset which can be found here: https://www.kaggle.com/datasets/marceloventura/the-berka-dataset?select=loan.csv
